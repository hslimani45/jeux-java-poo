# Projet Java

Projet réalisé en L2 Informatique à l'Université d'Orléans.

L'application permet de jouer en console à plusieurs jeux :
- Morpion
- Puissance 4
- Nim

On peut jouer à deux joueurs ou contre l'ordinateur.

Le projet respecte une architecture MVC avec les packages modele, vue et controleur.

Le programme gère notamment :
- les coups invalides
- la détection de victoire
- plusieurs parties à la suite
- différents niveaux pour l'IA
- une stratégie spécifique pour le jeu de Nim basée sur le XOR

Un diagramme de classes de conception a aussi été réalisé pour représenter l'organisation du projet.

Technologies utilisées :
Java, IntelliJ IDEA
